# Lessons Learned

## 一、从《烷烃与环烷烃》学到的

### 有效模式
1. **结构 → 写名称**连续训练，比规则说明更有效。
2. **名称 → 写结构**能覆盖反向输出。
3. “伯/仲/叔”等规律适合用**一张关联表**压缩。
4. 构象适合给明确画图区。
5. 反应题要求“底物 + 条件 + 产物”完整输出，而不是只问“产物是什么”。

### 可复用形式
- C1–C11 名称默写
- 常见烷基名称/结构互写
- 系统命名一排结构
- 环烷烃、桥环、螺环结构→名称
- Newman 构象画图
- 完整反应式

## 二、从《立体化学》v1.0 → v5.2 学到的

### v1 的问题：像讲义
- 太多概念框；
- 太多“定义 + 解释”；
- 结构题不足；
- PPT 被重新复述，而不是转成主动回忆。

### v2 的进步：题型化
开始加入：
- CIP 表格
- R/S 结构题
- 名称训练
- 关系判断
- 构象题

### v3/v4 的关键改进：覆盖 + 易错点
- 重新逐页核对 PPT；
- 把用户真正卡住的问题嵌入对应知识点；
- 删除“最后自测”式独立模块；
- 不再把疑惑集中堆到最后。

### v5 的关键改进：结构图质量
主要教训：
- 分子式“有内容”还不够，必须“看得清”；
- A/B/C/D 四个结构若强塞一行，很容易标签截断；
- 椅式、Newman、锯架式必须留足空间；
- 复杂结构可从 PPT 高分辨率裁图；
- PDF 要逐页渲染肉眼检查。

## 三、立体化学中值得复用的题型例子

### 1. 对称因素与手性
给具体结构，填写：
- σ
- i
- C*
- 是否手性
- 是否有光活性

比“手性的定义是什么”更有效。

### 2. Fischer + CIP + R/S + 完整命名
给 Fischer：
- 写 1>2>3>4
- 判断最低优先级在横/竖
- 判 R/S
- 写完整名称

易错点直接嵌入：
> 最低优先级在横线上时，最终结果反转。

### 3. 多手性中心
以丁-2,3-二醇为例：
- (2R,3R)
- (2S,3S)
- meso-(2R,3S)

要求：
- 完整名称
- 是否手性
- 是否有光活性
- 两两关系

这样一次覆盖对映体、非对映体、meso。

### 4. Newman 命名
先确定主链编号，再判断前/后碳分别是哪一位。

重点提醒：
> 前碳 ≠ C2；后碳 ≠ C3。  
> 前/后只表示观察方向。

### 5. R/S、D/L、(+)/(−)
用实际甘油醛、乳酸、葡萄糖结构放在一起。

结论：
- R/S：绝对构型
- D/L：相对构型
- (+)/(−)：实验测得旋光方向
- 三者不能互推

### 6. racemate / meso / diastereomer
不要只做定义表。

用酒石酸、2-溴丁烷、乳酸具体结构：
- 1:1 对映体混合 → 外消旋体
- 有 C* 但内部对称 → meso
- 非镜像立体异构体之间 → 非对映关系

### 7. 环己烷
先给最短规则：
- 环翻转：a ↔ e
- up/down 不变
- 大基团优先 e
- a 位有 1,3-二轴排斥

然后做：
- 单取代
- 顺/反-1,2-二取代
- 不同基团二取代
- 多取代
- 优势构象

### 8. 反应综合
正丁烷氯代：
- 写一氯代产物
- 比例
- 2-氯丁烷是否手性
- 样品是否旋光
- 为什么生成外消旋体

把旧知识和本章立体化学连起来。

## 四、不要再犯的错误

- 用“PPT第XX页”当最终标题；
- 用“本章核心目的”这类 AI 口吻；
- 只列“必须会的两个例子”却不画结构；
- 把 CIP 做成一个空白填“原子序数”；
- 只写 R/S 不训练完整名称；
- 只写结构名称但不给结构图；
- 另设“最后自测”重复前文；
- 结构编译成功但肉眼模糊仍然交付；
- 为缩页数牺牲结构可读性。


## 五、第三章《烯烃》v0.2–v0.7 重要教训（2026-10）

- 把“少文字”理解成“删必要规则”会导致命名、CIP、马氏、机理残缺；必须是**完整必要规则+真实分子结构+练习动作**。
- 表格不是目的。连续反应题不得反复堆表头；多步机制留横向全宽空间。练习版不能附带 PPT 标出答案的截图。
- 看过两份旧章 PDF 成品后，才理解长横向命名空间、按题型留不同作答区、练习/答案同题位等隐性设计，不能只读旧章 README。
- v0.5 得到明确认可的黑白矢量结构和最初知识骨架是**冻结基线**；后续小版本局部更正，不因模仿反馈丢掉原有成功设计。
- v0.6→v0.7 修了散落的试剂标签、部分表格重叠和机理图；**编译成功不等于反应条件、立体化学全部正确**。
- 完整失败分析：`docs/FAILURE_ANALYSIS_ALKENES.md`；技术和题型设计：`docs/DRAWING_AND_LATEX_PIPELINE.md`、`docs/EXERCISE_DESIGN_REACTIONS.md`。
