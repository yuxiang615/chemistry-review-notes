# 多轮审查 Checklist

> **新强制门槛**：逐题检查：1) 学生能看到具体底物和明确任务；2) 完整反应/机制在答案中是**可见的结构和带条件箭头**，不能用“应画”文字代替；3) 同题练习版没有答案截图；4) 分隔横线未压到两侧图、文字、箭头和注解；5) 常规结构字号/线重/显色统一；6) 与上一版认可页比较确认没有损失。化学证据不足的题必须在内部标待核，禁止仅凭 XeLaTeX 成功宣布无化学错误。详见 `docs/EXERCISE_DESIGN_REACTIONS.md`。


每次生成较完整版本后按顺序执行。

## Round 1 — 架构审查

- [ ] 是否仍然像 PPT 逐页复述？
- [ ] 能转成结构题/命名题/判断题的内容是否已经题型化？
- [ ] 是否存在“概念表很多，但结构太少”？
- [ ] 是否存在 AI 式标题或编辑口吻？
- [ ] 是否有无价值的彩色框过多？

## Round 2 — PPT 覆盖审查

逐页核对：
- [ ] 典型分子式是否纳入？
- [ ] 课堂题是否纳入？
- [ ] PPT 已给出的名称是否纳入？
- [ ] 老师强调的特殊画法是否纳入？
- [ ] 前后分散但应合并的内容是否合并？
- [ ] 用户明确删除的内容是否真的删除？

建议使用 `templates/coverage-checklist.md`。

## Round 3 — 必要补充审查

- [ ] PPT 未写完整名称的重点结构，是否补完整命名？
- [ ] 做题必须用到的规则是否补齐？
- [ ] 补充是否只服务于考试输出？
- [ ] 是否避免扩成课外百科？

## Round 4 — 化学正确性审查

- [ ] CIP 优先级
- [ ] R/S
- [ ] D/L
- [ ] (+)/(−)
- [ ] cis/trans
- [ ] a/e
- [ ] up/down
- [ ] meso/racemate/diastereomer
- [ ] 系统命名
- [ ] 反应条件与产物
- [ ] 构象稳定性

## Round 5 — 练习/答案一致性

- [ ] 每个练习空格都有答案
- [ ] 每个答案都能找到练习位置
- [ ] 练习版没有意外泄露答案
- [ ] 答案版没有新增练习版不存在的大段内容
- [ ] 表格行数、结构顺序一致

## Round 6 — 分子结构视觉审查

重点肉眼放大检查：
- [ ] CH3/H/Br/Cl 等标签是否撞线
- [ ] 楔线/虚楔是否分得清
- [ ] Fischer 横竖关系是否清楚
- [ ] Newman 前后碳是否清楚
- [ ] 锯架式取代基是否分得开
- [ ] 椅式 a/e 是否可读
- [ ] 课堂 A/B/C/D 选项是否各自完整
- [ ] 环状结构是否被裁切
- [ ] 字号是否足够大

若普通段落排版不稳定：
> 把结构放进固定宽度表格单元格，或单独占行。

## Round 7 — PDF 页面审查

- [ ] XeLaTeX 编译通过
- [ ] 无 overfull 导致内容出界
- [ ] 无图片裁切
- [ ] 无异常大空白
- [ ] 无标题孤零零留在页底
- [ ] 作答区足够
- [ ] 不为省页数硬塞内容
- [ ] 章节间分页自然

必须把 PDF 渲染成图片逐页看。

## Round 8 — 用户历史疑惑回查

拿逐页讨论记录逐项检查：
- [ ] 每个“我不懂”是否在成品中再次出现？
- [ ] 是否放在对应知识点附近？
- [ ] 是不是通过结构/题目而非聊天式说明解决？
- [ ] 是否避免在文末重复放“最后自测”？

## Round 9 — 收尾门槛

只有全部满足才进入收尾：
- [ ] 用户没有指出未解决的结构显示问题
- [ ] PPT 覆盖表无高价值遗漏
- [ ] 练习版/答案版均完成
- [ ] 整份渲染视觉检查通过
- [ ] 用户明确说“可以收尾/这一章结束”

否则继续小版本迭代。
