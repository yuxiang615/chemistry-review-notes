# 从课件反应变成真正可写的练习

## 决策规则：按要训练的“输出动作”设计题目

### A. 完整反应默写（记忆试剂/条件）
- 题干给**明确的具体结构** + **目标产物结构**，或给具体结构 + 特定反应类别（若产物需自行判断）。
- 学生在**整行或多行留白**独立写“底物 + 试剂/浓度/温度/溶剂 + 中间体（如需要） + 主要产物”。
- **不能**提前把试剂、条件填好只让学生写最终产物；也不能仅给“某个烯烃发生 HX 加成”这种空泛题干。
- 例：给丙烯结构和丙-2-醇结构，要求写浓 H₂SO₄ 加成→水解的完整两步式；留 3–5 cm 高可书写空间。答案版箭头条件齐全。
- 另给丁-1-烯和 2-甲基丙烯迁移，避免只会背单个例子。

### B. 条件已知的迁移题（预测未知产物）
- 给**具体底物结构 + 试剂与条件**，要求画完整产物、立体关系、可能的主要/次要路径。
- 换烯键位置、取代类型及反应环境（例如 HBr vs HBr/ROOR、Br₂/CCl₄ vs Br₂/H₂O）。
- 这是 A 的**补充**而非替代。

### C. 机理题（必须真画）
- 题干给真实底物与完整起始试剂，明确“画每个必要中间体和**成键/断键电子箭头**”。
- 参考顺序：HX 质子化→碳正离子比较→可能的 1,2-迁移→亲核进攻；过氧化物效应分链引发/链传播；X₂ 与 HOX 先卤鎓离子→背面进攻；BH₃/H₂O₂ 解释四中心同步加成并画产物。
- 答案版不能只写“比较稳定性/应画箭头”。
- 讲解短句放图边：用于辨析而非取代关键结构。

### D. 氧化条件横向对照与结构反推
- 同一个烯烃**画出** O₃/Zn-H₂O、浓热酸性 KMnO₄、稀冷碱性 KMnO₄、过氧酸等各自完整产物，不用只有“某醛/某酸”的口头描述。
- 对裂解产物另出反向题：看**两种真正羰基结构**，画原烯烃。
- 反应试剂**写在箭头上**，答案不能散成三张不相连的结构图。

### E. 命名/立体化学题的空间
- 结构→名称：左是真实足尺寸分子图，右留能写**完整中文系统名与构型**的长空间。
- 名称→结构：左给完整名称，右留实际二维画图区；复杂环系的课件红色编号不能留在练习题上。
- syn/anti：给底物与条件，画实楔/虚楔；必要时判断一对对映体、meso、dl。

## 什么时候用表格

- 同一批结构逐行比较命名、稳定性、多个试剂或对照条件，表格确实带来对应关系时才用。
- 一套练习只出现**一次通用表头**，绝不能每题重复“给定结构与任务—完整反应式”。
- 一般反应默写采用**一行任务说明 + 整行手写留白**；练习版别再画冗余的套内矩形。
- 文字规则：精简但**不漏**主链/双键编号、CIP、马氏、重排、syn/anti、不同氧化条件等实际考试依据；一条规则后应跟真实结构示范和可独立完成的题目。
