# 第三章《烯烃》v0.2–v0.7：失误归因与防回归案例

> 此文是设计复盘，**不是化学答案权威来源**。已有 v0.7 仍需逐题化学复核；绝不能因为页数增加或编译成功便宣布完全正确。以下由第三章实际反复反馈、旧章成品对照和源码审查形成。

## A. 原规范中容易被误读、导致跑偏的指令

| 原指令／遗漏 | 错误执行方式（发生过） | 以后必须怎么执行 |
|---|---|---|
| “主动回忆为主；知识点最少文字” | 删除命名、CIP、马氏取向等必要规则，只保留单行问题和短空格（v0.2） | **必要规则 → 真实结构/完整示范 → 对应回忆练习**；少的是重复讲解，不是考试依据 |
| “优先表格化” | v0.4 每道题重复“给定结构与任务／完整反应式”等表头，出现密密麻麻窄格 | 表格**仅在能形成对应比较**时使用；同类题一次表头；多步反应横向全宽留白 |
| “给条件 → 产物” | 只给烯烃+HBr，填一个产物；学生无法练完整条件及方程式 | 至少两种互补训练：记忆题给**具体底物+目标或反应类别**，独立写试剂/条件/中间体/产物；迁移题给底物+条件，画含立体化学的产物 |
| “复杂图可裁 PPT” | v0.3 含完整课件截图：规则、反应条件和**答案同时出现于练习版** | 优先重画成题干结构；只有无法可靠重画时裁**不带答案**的局部；完整原图最多放答案解析 |
| “优先 chemfig/TikZ” | v0.4 由临时宏手绘普通分子，线宽字号风格不统一，环系难读 | 普通二维底物/产物优先 RDKit 生成**黑白 SVG/PDF**；特殊空间结构 Ketcher 人工修；chemfig/TikZ 排反应箭头、电子箭头及投影 |
| “旧例子学习：读 README/代码片段” | 只模仿旧章表格外表，忽略旧章 PDF 真正的行高、留白、题目动作 | 新章开工前**必须实际打开练习版和答案版成品页面，比较相同题位**；若成品不在可访问存储，明确缺口，不能谎称已学习 |
| “PPT 覆盖核对” | 将内部覆盖审查、83–102 页原图复核等放进学生 PDF | 覆盖表只做内部 QA；课堂综合题**融入知识点/综合模块**；不要将整套原图当文末附录 |
| “PDF 编译检查” | 只看过编译和无 overfull 就认为无重叠（v0.6） | 全页栅格渲染**肉眼逐页**；长答案表行高度必须测**左右两列**；检查文字/横线/箭头重叠 |
| “同一源码生成两版” | v0.4 部分答案仍是“应画图/见 PPT”，不是实际结构 | 每道题有唯一 ID；答案版必须画出**结构、机理箭头及必要立体化学**，不能只述画法 |
| “已经被夸奖的版本继续完善” | 每次模仿新意见反而丢掉上一版的合理章节架构 | 先复制/标记**被确认的基线**，每轮只修反馈目标，交付前用视觉回归对照基线 |

## B. 第三章版本轨迹：正确的方向从哪里来

- **v0.2**：范围广却偏文字，课件命名结构、化学反应式及机制覆盖深度不足；内部覆盖总结误进入正文。
- **v0.3**：补 PPT 截图能看到结构，但练习版显示了试剂/产物答案；反应仍以文字和局部填空为主。
- **v0.4**：模仿前两章的表格外观，但重复标题、短横线和未显示的课件图破坏了使用体验；有些答案只写“应该怎么画”。
- **旧章真正的启发**：必须对照练习版/答案版 PDF 的**实物页面**，学习答案如何填在同一题位、画图区多大、规则与图的比例，而不是模仿配色或表格数量。
- **技术样张**：RDKit 二维结构 → SVG → PDF → XeLaTeX，黑白矢量分子图与完整反应默写空间得到确认；试样通过并不代表所有桥环立体题自动正确。
- **v0.5**：保留第三章原有知识链，改黑白矢量结构，按答案动作留空白，练习与答案两版共源。这是被用户明确认可的**冻结式版式基线**。
- **v0.6**：在 v0.5 基础上增补后半章课堂综合题、细节规则；暴露反应式仅散放结构、试剂未写在箭头上，长答案压线的问题。
- **v0.7**：修正部分箭头/图文/左右列行高并补立体产物；仍是**迭代稿**，不可认定所有复杂课堂题已独立化学验证。

## C. 前两章成品展示出的设计规律

- **烷烃与环烷烃 v5.1**：名称↔结构有充足横向/二维空间；伯仲叔关联表**只在适当时使用**；完整反应默写每格写整套底物、条件和产物；机理按链引发/增长/终止拆分。
- **立体化学 v5.2**：真实结构贯穿 CIP→R/S→完整名称；Fischer、Newman、锯架、椅式须本身占足够空间；重复出现的概念被真实结构和易错辨析吸收。
- **不同处**：第三章反应和机理规模比前两章大，应保留自己的“结构→命名→加成→氧化→制备→综合”主线，不能按上一章题数和目录盲目复制。

## D. 永久防回归验收（每次交付都检查）

1. 学生 PDF 不出现“覆盖核对／审查记录／原图复核／制作过程”等章节。
2. 练习版无任何同题答案截图；完整反应题出现明确**底物和目标/反应任务**，不是“某烯烃+某试剂”占位文字。
3. 所有重点反应包括实物结构、试剂/条件**标在箭头上**、真实产物；机制题有箭头／中间体的实际绘图。
4. 普通分子同一矢量风格，避免忽大忽小、局部浅灰；桥环/楔线单独人工审查。
5. 长答案行高测左右内容；每页观察基线、横线和注解是否碰撞；练习留白足够手写。
6. 每次优先**局部修已批准版本**，对改动页和可能被分页影响的相邻页做前后视觉对比。
7. 不把课件中的未经复核假设或外部化学知识装成课程答案；在**内部核对表**注明待核事实。
