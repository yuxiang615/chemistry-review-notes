# 如何学习已有成品例子

**学习输入的升级**：不要再把旧章 README 当作真实 PDF 的替身。必须依次核对旧章练习版和答案版的相同题位，观察文字/图比例、规则位置、留白尺寸、矢量线条和分页；记录与当前章的适用/不适用项。如果实际 PDF 尚未存档或工具不可访问，要报告这一限制，然后从 `examples/*/CASE_STUDY.md` 和可重编译例子中学习；不得虚称“已完整复查旧章”。版本反例必读 `docs/FAILURE_ANALYSIS_ALKENES.md`。


新章节开始时，不是简单“看一眼旧 PDF”，而要做一次**例子学习 pass**。

## 1. 学什么，不学什么

### 学可迁移的东西
- 题型怎么设计；
- 哪些知识适合表格；
- 哪些知识适合画图；
- 练习版如何留空；
- 答案版如何给短理由；
- 结构式如何排版；
- 一页信息密度如何控制；
- 用户历史疑惑如何嵌入；
- 版本迭代时为什么修改。

### 不机械复制
- 不复制上一章的章节结构；
- 不复制上一章的题数；
- 不因为上一章有某个表格，本章也强行做同样表格；
- 不把上一章的具体化学内容当作本章事实来源。

旧例子是**设计参考**，新 PPT 才是本章内容主干。

---

## 2. 每次新章节先读两类例子

### 例子 A：烷烃与环烷烃
重点学习：
- 大量“结构 → 名称”；
- 名称 → 结构；
- 规则压缩成表；
- 构象直接画；
- 反应式完整输出；
- 练习/答案一致。

### 例子 B：立体化学 v5.2
重点学习：
- 把 v1 的讲义式内容逐步改成题型；
- 多种立体表示法如何画清楚；
- 用户疑惑如何变成短辨析；
- 多轮 PPT 覆盖审查；
- 分子式/结构图的视觉修正；
- 复杂课堂选择题如何通过固定单元格或高分辨率裁图避免糊掉。

---

## 3. 例子学习后要先产出“设计摘要”

在开始写新章 LaTeX 前，内部先回答：

1. 本章最适合的 3–6 类主动回忆题是什么？
2. 哪些地方需要完整命名训练？
3. 哪些结构必须画图，不能只写文字？
4. 哪些内容可以一张表压缩？
5. 哪些是用户反复容易错的？
6. 哪些 PPT 结构视觉上高风险？
7. 哪些旧章经验能直接复用？
8. 哪些旧章做法这章反而不适合？

再开始排版。

---

## 4. 例子不是一次性参考，而是审查标准

每轮审查时都可以反问：

- 这页是不是又变成“讲义”了？
- 有没有比“填定义”更好的结构题？
- 为什么这里只写了名称却没有结构？
- 为什么这里只有结构却不要求命名？
- 这个结构是否比旧成品更难看清？
- 如果学生不看 PPT，只做这份练习，能不能主动回忆出课件核心？

---

## 5. 版本迭代要吸收原因

不是只保存“最新版是什么样”。

要保留：
- v1 为什么失败；
- v2 为什么改；
- v3 为什么重新查漏；
- v4 为什么融入历史疑惑；
- v5 为什么重做结构图；
- v5.2 为什么还要修课堂 A/B/C/D 的清晰度。

这样下一章可以从较高起点开始，而不是重新经历同样错误。
