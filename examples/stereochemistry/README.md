## 特别值得复用的短辨析

- 有 σ → 镜像可重合 → 非手性。
- 一个 C* 通常对应一对对映体；多个 C* 时要检查整个分子的对称性。
- Fischer：横前竖后；最低优先级在横线上时 R/S 结果反转。
- Newman 的前/后碳是观察方向，不是系统命名编号。
- R/S、D/L、(+)/(−) 是三套不同体系。
- 外消旋体是混合物；meso 是单一化合物；非对映体是两个结构之间的关系。
- 环翻转时 a/e 互换，但 up/down 不变。
- 优势构象 = 能量更低 = 更稳定 = 平衡比例更高。
- 2-氯丁烷单个分子有手性，但非手性条件生成 R/S 等量混合时样品无净旋光。
