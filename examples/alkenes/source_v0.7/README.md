# 烯烃 v0.7 实际 LaTeX 主文件（源文件归档）

这里存放从本次对话中真实上传的 **v0.7 `master_v0.7.tex`**，以及练习/答案入口。用来分析实际章节结构、规则与题目的 LaTeX 实现及已知风险，不意味着 v0.7 的所有复杂反应已完成独立化学审查。

**可重现性说明**：主文件使用大量 `assets/*.pdf` 矢量分子图（原 v0.7 源码包内由 `build_assets.py` 生成）以及少量课程复杂环系的 `assets/*.png`，这些二进制资源目前**尚未在 GitHub 中归档**，所以此目录单独克隆后不可立即编译为 v0.7 全章 PDF。普通分子示范可先运行上一级 `draw_molecules.py`；完整二进制源包和旧章 PDF 入库计划及状态见 `docs/PROVENANCE_AND_ASSETS.md`。不应以缺失资源时的编译输出替代已核查成品。
