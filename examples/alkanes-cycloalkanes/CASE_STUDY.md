# 以真实 v5.1 成品为标准的设计案例

练习版 11 页、答案版 10 页：页数本身不是评价标准，两个版本的**对应题位**才是。该案例来自本项目讨论中实际提供的四份旧章 PDF 中的 v5.1 成品，不是据 README 虚构页面。

- 练习版第 2 页：C1–C11 名称默写和常见烷基名称→结构，两栏表格刚好适合**重复同一动作**；不是所有反应题都应照搬。
- 第 3–6 页：从真实结构写完整中文系统名，分支命名用**短规则填空紧跟结构题**；复杂桥环/螺环留长横向名称空间，题面不写答案编号。
- 第 7–8 页：构象采用真正的独立二维画图区；“结构图是否画得下”决定高度，不采用统一短横线。
- 第 8–9 页：完整反应每格写底物+试剂/条件+产物；机理按链引发/传播/终止展开，**不只写最终产物**。
- 第 10–11 页：真实课堂多步题，明确底物、已有试剂与目标，不能把原图整张粘进练习版。

**抗机械模仿**：这个案例说明“什么时候用表格”和“如何分配答题动作”；第三章保留自身的反应知识地图，不能按 v5.1 原章节数量和题型密度硬套。参考文件实际入库状态见 `docs/PROVENANCE_AND_ASSETS.md`。
