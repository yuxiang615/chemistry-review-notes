# Example — 烷烃与环烷烃

这一章是“题型化”的基础参照。

## 值得学习的设计

### 1. 结构 → 名称
连续放多个结构，右侧直接要求“写中文系统名称”。

这比：
> 系统命名规则有哪些？

更接近考试输出。

### 2. 名称 → 结构
常见烷烃、烷基使用双向训练。

### 3. 规则压缩成表
把三类 H 活性、自由基稳定性、氯代/溴代选择性放在同一张表，减少重复解释。

### 4. 构象用画图区
甲烷、乙烷、正丁烷、环烷烃构象不靠文字描述，而是让学生直接画。

### 5. 反应要求完整格式
每格写：
> 底物 + 试剂/条件 + 产物

而不是把“写条件”“写产物”拆成零碎问答。

## 对后续章节的启发

遇到一个知识点时，先问：
> 它能不能变成一个“输出动作”？

能，就优先做题，而不是先写一段讲义。
